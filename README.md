Segmented customers into High, Medium, and Low value groups using SQL CASE statements and identified that Medium Value customers contributed most to churn (6 out of 7 customers), enabling targeted retention campaigns.
Analyzed churn by contract type using SQL aggregation and discovered that Month-to-Month contracts had the highest churn (8 customers).
Examined payment method impact on churn using SQL GROUP BY and found Electronic Check users were more likely to churn, suggesting process improvements.
Visualized customer churn by tenure in Power BI stacked bar chart and found that New Customers (<12 months) were most at risk, guiding early-stage retention strategies.
Ranked customers by monthly charges using SQL window functions to identify top paying customers for upsell opportunities.
Built an interactive Power BI dashboard including KPI Cards (Total Customers, Churn Customers, Churn Rate), Churn by Contract Type & Payment Method, Customer Segmentation, and Tenure vs Churn charts for management reporting.
